# 📊 Excel Minor Project

## 📌 Project Overview

This project is an **Excel-based Data Analysis Minor Project** completed using Microsoft Excel.

The project focuses on analyzing the given dataset and solving the provided questions using Excel formulas, functions, sorting, filtering, and data analysis techniques.

- Analyze the given dataset using Microsoft Excel

- Perform calculations based on the given questions
- Use sorting and filtering techniques
- Obtain accurate results from the dataset
- Present the results in a structured Excel workbook
